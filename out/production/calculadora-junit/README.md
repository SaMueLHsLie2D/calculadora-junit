# Calculadora - JUnit

Este projeto consiste em uma calculadora simples desenvolvida em Java com testes unitários usando JUnit 5.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão (com verificação de divisão por zero)
- Potenciação

## Tecnologias

- Java
- JUnit 5

## Execução dos testes

Para executar os testes unitários, utilize uma IDE compatível com JUnit 5 ou configure um projeto Maven/Gradle com a dependência do JUnit.
